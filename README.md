# Student Grade Tracker

A Java console application to manage student grades.

## Features
- Add students
- Add grades for each student
- Calculate average, highest and lowest score
- View a summary report of all students

## Technologies
- Java
- OOP (classes and objects)
- ArrayList

## How to Run
1. Clone the repository
2. Open the folder in any Java IDE
3. Run Main.java

Made during the CodeAlpha Java Programming Internship.
